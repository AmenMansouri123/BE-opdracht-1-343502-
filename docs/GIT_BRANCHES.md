# Git Branches - Magazijn Jamin

Voor dit project wordt Git gebruikt voor versiebeheer.

## Feature leveringsinformatie

Branch:

feature_leveringsinformatie_product

Deze branch is gebruikt voor het ontwikkelen van de leveringsinformatie van producten.

Hierin zijn de scenario's voor Mintnopjes en Winegums gerealiseerd.

## Feature allergeneninformatie

Branch:

feature_allergeneninformatie_product

Deze branch is gebruikt voor het ontwikkelen van de allergeneninformatie van producten.

Hierin zijn de scenario's voor Zoute Ruitjes en Cola Flesjes gerealiseerd.

## Main branch

Na het afronden van de opdracht worden de gemaakte features samengevoegd met de main branch.

Daarna wordt de main branch naar GitHub gepusht.
