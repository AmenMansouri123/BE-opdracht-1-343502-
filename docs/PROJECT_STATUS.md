# Project Status - Magazijn Jamin

## Status

Het project Magazijn Jamin is gerealiseerd voor BE-opdracht 01.

De twee user stories zijn uitgewerkt:

- Leveringsinformatie van producten
- Allergeneninformatie van producten

De bijbehorende happy en unhappy scenario's zijn gerealiseerd.

## Database

De database bevat de zes vereiste specificatietabellen met primary keys, foreign keys en systeemvelden.

De create scripts, testdata en database-export zijn opgeslagen in de map `db`.

## Documentatie

De projectdocumentatie is opgeslagen in de map `docs`.

## Git

Voor de user stories zijn feature branches gebruikt.

Het project bevat minimaal 20 commits voordat de opdracht definitief wordt ingeleverd.

## Laatste stappen

Voor het inleveren moeten de volgende stappen nog worden uitgevoerd:

- Video opnemen van maximaal 60 seconden
- Video opslaan in de map `vids`
- Final commit maken
- Feature branches samenvoegen met main
- Main branch naar GitHub pushen
- GitHub-link en video inleveren
